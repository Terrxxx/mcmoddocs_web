`<参数>` 必填，`[参数]` 有默认值。坐标参数需要 X Y Z 三项；玩家参数使用目标选择器。需要作弊/管理权限的指令应由有权限的地图管理员执行。清空、销毁、刷新前先备份存档。



## /yrxs_trade_enable_trade



设置玩家是否能在交易行交易。



权限：`game_directors`；需要作弊：是。



```text

/yrxs_trade_enable_trade <玩家选择器:target> <Bool:bool>

```





## /yrxs_trade_exit



强制玩家退出交易行UI。



权限：`game_directors`；需要作弊：是。



```text

/yrxs_trade_exit <玩家选择器:target>

```





## /yrxs_trade_money



获取玩家交易行的货币信息。



权限：`game_directors`；需要作弊：是。



```text

/yrxs_trade_money <set> <玩家选择器:target> <货币值:int>

```





```text

/yrxs_trade_money <list> <玩家选择器:target>

```





```text

/yrxs_trade_money <add> <玩家选择器:target> <货币值:int>

```





```text

/yrxs_trade_money <remove> <玩家选择器:target> <货币值:int>

```





```text

/yrxs_trade_money <default> <货币值:int>

```





## /yrxs_trade_replenishgoods



一键补货。



权限：`game_directors`；需要作弊：是。



```text

/yrxs_trade_replenishgoods <物品标识符:item> [物品数据值:int]

```



- `物品数据值` 默认：`0`。



```text

/yrxs_trade_replenishgoods <all>

```





## /yrxs_trade_tips



对玩家发送文本提示。



权限：`game_directors`；需要作弊：是。



```text

/yrxs_trade_tips <玩家选择器:target> <文本:str> <持续时长:int>

```







不要直接修改 `trade_money` 代替交易行货币操作。`default` 分支只接金额，不接玩家选择器。
