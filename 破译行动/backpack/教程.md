## 打开与移动

PC 默认 Tab 打开背包，长按打开菜单；单击查看物品信息，拖动移动，F 或双击快捷移动。主手用 1–3 切换，4 使用当前口袋槽，长按 4 呼出口袋选择。移动端使用屏幕按钮。



绿色落点表示当前可放，红色表示不可放；物品体积、朝向、装备类型、白黑名单和搜索状态都可能影响结果。点击已装备胸挂或背包查看内部，长按拖动才进行移动。



## 死亡盒与整件转移

手动把玩家胸挂/背包拖到死亡盒的对应装备栏，可携带内容整件转移或对调。拖普通物品到死亡盒背包入口，应尝试存入背包内部。



快捷移动不进行物品对调。死亡盒装备比当前容量更大时可以升级；同容量或更小时作为物品收纳。内部物品需要按规则安置，空间不足会失败，先清理再取。



## 安全箱与钥匙卡包

未开始游戏时点击相应图标进入装载与权限界面，选择容量档位并按提示使用权限卡。缩容时先清理超出容量的物品。开始后点击进入物品介绍，不再进入权限管理。



## 管理员控制战局

```
/yrxs_isstart @s true
/yrxs_isstart @s false
```

开始会记录当前装备价值；重复设置为开始不应重置同一局的价值基准。结束后再开始才建立新基准。默认模式切换选项目前锁定，不应按旧版原版背包模式说明操作。



## 查询分数

```
/scoreboard players list @s
/scoreboard objectives setdisplay sidebar player_weight
```

第二条把携带重量展示到侧边栏，会替换当前侧边栏显示项。分数为整数十分之一千克；79 表示截断后的 7.9kg，不是精确到两位小数的原始重量。
