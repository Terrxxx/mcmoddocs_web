## /yrxs_clonesafeblock



克隆某个位置的保险箱到另一个位置。



权限：`game_directors`；需要作弊：是。



```text

/yrxs_clonesafeblock <起始位置:pos> <目标位置:pos>

```





## /yrxs_destroysafeblock



破坏保险箱方块。



权限：`game_directors`；需要作弊：是。



```text

/yrxs_destroysafeblock <位置:pos>

```





## /yrxs_give_ccard



获取指定自定义钥匙。



权限：`game_directors`；需要作弊：是。



```text

/yrxs_give_ccard <玩家:target> <普通|高级|卓越|罕见|奇异|隐秘> <钥匙数据值:int> [数量:int]

```



- `数量` 默认：`1`。



## /yrxs_out

权限：`any`；需要作弊：否。



```text

```

## /yrxs_setsafeblock



设置某个位置为保险箱。



权限：`game_directors`；需要作弊：是。



```text

/yrxs_setsafeblock <位置:pos> [方块id:enum] [tileData:int] [是否创建随机物品:bool]

```



- `方块id` 默认：`"safe3x3_block"`。

- `方块id` 可选：`safe3x3_block`、`safe3x5_block`、`safe6x4_block`、`safe_block_need_card0`、`safe_block_need_card1`、`safe_block_need_card2`、`safe_block_need_card3`、`safe_block_need_card4`、`safe_block_need_card5`、`box_block0`、`box_block1`、`box_block2`、`safe_block_music`、`clothing1`、`clothing2`、`drawer1`、`drawer2`、`drawer3`、`trash_can`、`cover`、`pc_chassis`、`suitcase`。

- `tileData` 默认：`0`。

- `是否创建随机物品` 默认：`false`。





背包、安全箱、仓库及战局指令见[背包指令](../backpack/指令.md)。交易与门禁指令分别见[交易行](../trade/指令.md)和[钥匙门](../door/指令.md)。

## 计分板映射数据介绍



| 计分项 | 用途 |

|---|---|

| `player_equip_money` | 战备价值：主手、副手、护甲、胸挂和背包本体；开始时冻结基准 |

| `player_get_money` | 战局内当前全身价值减去开局装备价值，可为负数 |

| `player_wh_money` | 仓库价值 |

| `player_weight` | 携带重量，kg×10 后截断，例如 7.95kg 显示 79 |

| `player_all_money` | 全身价值，含口袋及胸挂、背包、安全箱中的物品，不计钥匙卡包和其内容 |

| `trade_money` | 交易行余额 |



未开始时背包顶部显示装备价值，开始后显示收获价值。价值估算需要交易价格；不是未出售物品已经兑换成的货币。重量仍沿用库存统计范围，包含钥匙卡包，不采用价值的排除规则。

计分板用于查询模组统计值，不作为修改库存或余额的入口。余额请使用 `/yrxs_trade_money`。

```mcfunction
scoreboard players list @s
```
