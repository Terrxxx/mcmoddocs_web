## 第一次使用
1. 在同一世界启用对应行为包、资源包及其实际要求的前置组件。更新后完整退出并重新进入，不能只热更新脚本来验证贴图、动画或指令注册。
2. 放置一个容器，瞄准后使用交互按钮；PC 默认按 F。自定义过按键时以设置页为准。
3. 按容器要求完成解锁，等待物品搜索，再拖动或快捷移动物品。
4. PC 默认 Tab 打开背包，P 打开设置，H 查看附近掉落物；移动端使用对应 HUD 控件。

## 配置自己的物品池
1. 使用物品池编辑工具建立物品池，填写名称、品质分组和候选物品。
2. 调整概率模型、权重和生成数量。权重表示同一抽取范围内的相对占比，不直接等同于最终刷新概率。
3. 保存物品池，再用保险箱编辑工具选中世界中的目标容器。
4. 选择刚保存的池，设置刷新、解锁及开启音效，点击保存。
5. 重新打开编辑器核对；在测试存档刷新该容器，实际检查结果。

例如：同一候选组只有两件物品，权重为 1 和 9 时，组内抽到它们的相对概率是 1:9；仍须结合品质抽取规则理解最终概率。不要为了提高某一件物品的概率而误改整个品质组。

## 大型容器机关
| 机关 | 操作与成功条件 |
|---|---|
| 双扣锁 | 调整两枚锁销，对齐黄色标记后释放 |
| 封签拆解 | 携带模组剪刀，先剪封签，再各操作两次锁杆；原版剪刀不代替模组工具 |
| 供电接线 | 点击旋转导电片，把左侧电源接到右侧锁机，避开红色短路格，完成后点接通 |
| 压力平衡 | 按住按钮减压，松开增压；在绿色区间连续保持 5 秒 |
| 信号配准 | 调整频段匹配目标，每段稳定 1.5 秒，完成三段握手 |


模组剪刀 `yrxs:seal_scissors` 有 32 点耐久，每次成功剪封签消耗 1 点。供电通路与 1–2 个短路格、压力绿区和信号目标在容器每轮刷新时重新随机，同轮反复打开不会重抽。压力绿区宽 5–10 刻度，中心在 45–55 之间。

一个机关同时由一位玩家操作；退出会中断连续稳定计时，已确认的封签、锁杆或握手阶段按本轮状态保留。

## 刷新与地图测试
```
/yrxs_safeblock_update block supply_chest
/yrxs_safeblock_update block flight_instrument_case
/yrxs_safeblock_update itemlist -1
```
以上分别按方块类型刷新补给箱、航空仪器箱，以及使用默认物品池的容器。刷新会改变容器当前轮次和物资，应先在测试存档验证；完整参数见[指令](指令.md)。

### 调整物品权重

在同一品质的候选组内，权重越大越容易抽中。例如只有两件候选物品且权重为 1 和 99，组内概率分别为 1% 和 99%；这不是物品跨所有品质的最终概率。
