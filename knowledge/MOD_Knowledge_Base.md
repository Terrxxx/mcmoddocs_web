## 2. 破译行动 主包

**组件码**: 4328266
**最终售价**: 1200 钻石（v3.0.0起由原价上调，因融合了《自定义保险箱》副包）

破译行动是一个类似"逃离塔科夫"风格的模组，核心玩法是：玩家在地图中搜索保险箱/容器获取战利品，死亡后物品会掉落在死亡盒中，其他玩家可以搜刮。

### 2.1 物品体系

#### 编辑工具类
| 物品名称 | 功能说明 |
|---------|---------|
| 自定义保险箱数据棍 | 用于编辑保险箱数据的编辑棍（点击保险箱方块进行配置） |
| 自定义物品池棍 | 用于编辑物品池模板的编辑棍（右键打开UI创建物品刷新池） |
| 自定义钥匙 | 用于编辑自定义钥匙的编辑物品 |
| 容器预设棍 | 用于编辑容器放下后默认的数据 |
| 自定义物品基础数据棍 | 设置物品的基础数据（体积大小、可堆叠数量、搜索时间偏移、物品重量） |
| 自定义禁放棍 | 设置主手物品栏/安全箱/仓库扩容卡禁放物品的列表 |

#### 功能物品类
| 物品名称 | 功能说明 |
|---------|---------|
| 仓库扩容箱 | 扩展玩家仓库的额外格数（最高9个），分为A-C三种 |
| 钥匙卡包权限卡 | 激活玩家更大的钥匙卡包（有时限版：7天、30天） |
| 安全箱权限卡 | 激活玩家更大的安全箱（有时限版：1天、7天、30天） |
| 史蒂夫黑卡 | 可以打开任意需要钥匙解锁的容器和钥匙门（仅1点耐久） |
| 灵魂 | 玩家死亡后生成在死亡盒中的特殊物品，记录死亡玩家信息（蓝色品质，无需搜索） |

#### 钥匙体系
- 5种钥匙用于打开特定的保险箱方块
- 钥匙耐久耗尽后自动删除
- 钥匙消耗顺序：背包 → 主手 → 口袋 → 安全箱 → 钥匙卡包
- 支持钥匙检视功能（背包中点击钥匙点击检视）

#### 收藏品
- 13种全新收藏品，只能从保险箱中获取，暂时无特殊意义
- 个别物品不能通过创造模式背包获得

### 2.2 核心功能

#### 保险箱/容器系统
- **容积系统**: 物品有体积占格（1x1、2x2、3x3 等，自定义上限 6x6）
- **容器类型**: 9种保险箱方块 + 多种收纳箱 + 手提箱 + 衣服 + 抽屉 + 垃圾桶 + 井盖 + 电脑机箱 + 服务器 + 黑曜石保险箱
- **容器大小**: 支持 3x3、4x4、5x5、6x6 等布局
- **解锁方式**: 密码解锁（固定密码 6MCUP）、音乐破译解锁、指定物品解锁
- **自动破译**: 容器打开后有搜索/破译时间，时间根据品质不同而不同，破译完成前无法获取物品

#### 物品刷新池
- 容器刷新的物品由"物品池模板"决定
- 物品池有6个品质等级: 白色、绿色、蓝色、紫色、金色、红色
- 物品刷新上限最大为 7 个
- 支持四种概率模型（普通/高级/奇异/隐秘），不同品质出现概率不同
- 保险箱定时刷新（全局统一计时，秒为单位）
- 容器刷新时有玩家搜索则不刷新

#### 概率模型详细数据

| 品质 | 普通 | 高级 | 奇异 | 隐秘 |
|------|------|------|------|------|
| 白色 | 32.57% | 30.74% | 28.93% | 25.97% |
| 绿色 | 26.06% | 24.27% | 22.50% | 21.10% |
| 蓝色 | 21.17% | 21.03% | 20.90% | 21.10% |
| 紫色 | 14.65% | 16.18% | 17.68% | 19.48% |
| 金色 | 4.88% | 6.47% | 8.03% | 9.74% |
| 红色 | 0.65% | 1.29% | 1.92% | 2.59% |

#### 背包系统
- 模组背包与原版背包相互独立
- 生存模式禁用原版背包系统，取代为模组背包
- 主物品栏替换为 3 格容器（无视体积大小）
- 口袋系统：可放置 5 个 1x1 物品，同步到主物品栏 4-8 格
- 快捷轮盘：长按呼出轮盘选择口袋物品快速切换
- 支持多种背包（2款默认免费 + 更多需购买《背包扩展》副包）

#### 安全箱
- 玩家单独存储物品的容器，死亡后不掉落
- 只能放置非禁放列表中的物品
- 大小可通过安全箱权限卡扩展（1x2、2x2、2x3、3x3）
- 可设置为 none（不显示安全箱）

#### 钥匙卡包
- 玩家单独存储钥匙的容器，只能放破译行动钥匙，死亡不掉落
- 可通过钥匙卡包权限卡扩大（x4到x9格）
- 管理员可使用指令锁定：`/ysce <玩家> true/false`
- 降级时多出格子的钥匙会被删除

#### 仓库系统
- 仓库区域方块：站在上面打开背包显示仓库
- 仓库扩容箱最高可放置 9 个扩展格
- 仓库一键整理自动堆叠可堆叠物品
- 仓库价值映射到计分板 player_wh_money

#### 死亡盒系统
- 玩家死亡后生成战利品箱
- 包含：主手、副手、装备、背包、口袋的所有可掉落物品 + 灵魂
- 灵魂（蓝色品质）记录死亡玩家信息，无需搜索
- 可控制是否生成死亡盒

#### 重量系统
- 物品默认重量 0.1kg
- 所有物品重量之和映射到计分板 player_weight
- 模组不做反馈，玩家可用指令实现超重效果（如缓慢debuff）
- 背包中可显示装备价值和物品重量

#### 旁观模式（v3.0.0）
- 开启后可快速查看容器不触发打开行为
- 可查看死亡盒和其他生存玩家的物品栏（只读）

#### 战备/收获价值系统
- 战备价值(player_equip_money)：当前携带装备、主手、背包的价值总和
- 收获价值(player_get_money)：去除携带装备后的总价值（需先 `/yrxs_isstart True`）
- 仓库价值(player_wh_money)：仓库所有物品价值总和
- 全身价值(player_all_money)：携带的所有物品价值总和（不含钥匙卡包）

### 2.4 教程：如何自定义

#### 设置自定义刷新物品池
1. 手持`自定义物品池棍`右键打开UI
2. 点击左下角 + 新增物品池模板
3. 设置属性：预设名、概率模型、物品列表
   - **重要**: 每个品质至少需要一个物品，否则物品池显示"未完工"且不会刷新物品
4. 保存后，手持`自定义保险箱数据棍`点击保险箱方块
5. 选择"物品刷新池"选项，选择刚创建的模板
6. 保存并退出

#### 修改容器爆率
- 某品质只出特定物品：将其他物品权重设为 0
- 提高/降低某物品概率：调整权重比例（如钻石权重 1、金锭权重 99，则出红时钻石概率 1%）
- 若某物品体积 > 容器体积，该物品不会刷新

#### 设置超重效果示例
```
# 40-60kg 时缓慢提示
effect @a[scores={player_weight=400..600}] slowness 1 3 true
title @a[scores={player_weight=400..600}] actionbar "§6你有点重!"

# ≥60kg 时超重提示
effect @a[scores={player_weight=601..}] slowness 1 5 true
title @a[scores={player_weight=601..}] actionbar "§c你超重了!"
```

### 2.5 常见问题

**Q: 为什么我设置好物品池后显示"未完工"？**
A: 物品池需要每个品质至少放置一个物品才能使用。检查是否所有品质都有物品。

### 2.6 已知限制/注意事项
- 物品存储在模组自定义数据结构中，不在原版背包，第三方交易模组无法直接使用（可将物品放主手/口袋检测）
- v2.0.0 前放置的保险箱数据在重构后失效，需要重新设置
- setblock/fill 指令填充的仓库/交易区域方块需重启存档才能生效
- 物品品质数据存储在 userData 的 ItemLevel 字段中，可能导致明明相同物品但第三方模组不允许交易

## 3. 破译行动：交易行

**组件码**: 1196419
**最终售价**: 486 钻石（v1.5.0起降低）

交易行是破译行动的附属模组，提供玩家间的物品交易市场功能。货币名为"哈基币"。

### 3.1 核心功能

- 交易行市场（系统上架 + 玩家上架）
- 系统回收物品功能
- 补货系统（价格动态浮动）
- 市场实时更新
- 交易记录查询
- 仓库板块（出售用）
- 交易区域方块（进入区域可交易，离开禁止）

### 3.2 特色物品
